Quy Định Khoảng Cách An Toàn Giữa Hai Xe Khi Tham Gia Giao Thông

Quy chuẩn tính khoảng cách an toàn tối thiểu theo tốc độ lưu hành trong điều kiện thời tiết khô ráo và bất lợi.

1. Điều kiện thuận lợi: Mặt đường khô ráo, tầm nhìn tốt

Tốc độ lưu hành:
V = 60 km/h

60 < V ≤ 80 km/h
Khoảng cách an toàn: 55 m

Lưu ý khi V < 60 km/h: Người lái xe chủ động giữ khoảng cách phù hợp với xe chạy liền trước xe của mình; khoảng cách này tùy thuộc vào mật độ phương tiện, tình hình giao thông thực tế để đảm bảo an toàn giao thông.

2. Điều kiện bất lợi: Mưa, sương mù, trơn trượt, đèo dốc, tầm nhìn hạn chế

Khi điều khiển xe trong các điều kiện thời tiết xấu hoặc địa hình nguy hiểm, người lái xe bắt buộc phải điều chỉnh khoảng cách an toàn lớn hơn trị số ghi trên biển báo hoặc trị số quy định khi thời tiết khô ráo (Hệ thống SmartADAS sẽ tự động tăng khoảng cách thêm +30%).

Mã Nguồn Python Đo Khoảng Cách (YOLOv8 + OpenCV)

Dành cho Raspberry Pi 4 / NVIDIA Jetson Nano trên ô tô

# ====================================================================
# SMART ADAS - PHẦN MỀM ĐO KHOẢNG CÁCH XE PHÍA TRƯỚC THEO TT 31/2019/TT-BGTVT
# Tối ưu hóa cho Camera iPhone 1x / WebCam USB
# ====================================================================

import cv2
import numpy as np
from ultralytics import YOLO

# 1. THÔNG SỐ HIỆU CHUẨN CAMERA IPHONE 1X
FOCAL_LENGTH = 820.0       # Tiêu cự pixel (f) của iPhone 1x ở độ phân giải 1280x720
REAL_CAR_WIDTH = 1.8       # Chiều rộng thực của xe ô tô con (mét)

def get_required_safe_distance(speed_kmh, is_adverse_weather=False):
    """
    Quy định khoảng cách an toàn tối thiểu theo Thông tư 31/2019/TT-BGTVT
    """
    if speed_kmh <= 0:
        base_dist = 5.0
    elif speed_kmh < 60:
        base_dist = 20.0    # Dưới 60km/h: Chủ động giữ khoảng cách phù hợp
    elif speed_kmh <= 60:
        base_dist = 35.0    # V = 60 km/h: 35m
    elif speed_kmh <= 80:
        base_dist = 55.0    # 60 < V <= 80 km/h: 55m
    elif speed_kmh <= 100:
        base_dist = 70.0    # 80 < V <= 100 km/h: 70m
    else:
        base_dist = 100.0   # 100 < V <= 120 km/h: 100m
        
    if is_adverse_weather:
        base_dist *= 1.3    # Điều kiện bất lợi: Tăng thêm 30%
        
    return base_dist

# 2. KHỞI TẠO MÔ HÌNH AI YOLOV8
model = YOLO('yolov8n.pt')  # Mô hình nhẹ Nano tốc độ cao
cap = cv2.VideoCapture(0)   # Camera ID

current_speed_kmh = 75.0    # Tốc độ xe (kết nối GPS thực tế hoặc OBD2)
is_bad_weather = False      # Chế độ thời tiết

while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break
        
    h, w, _ = frame.shape
    results = model(frame, verbose=False)
    
    min_safe_dist = get_required_safe_distance(current_speed_kmh, is_bad_weather)
    
    for r in results:
        boxes = r.boxes
        for box in boxes:
            cls_id = int(box.cls[0])
            label = model.names[cls_id]
            
            # Chỉ phát hiện phương tiện giao thông (car, truck, bus)
            if label in ['car', 'truck', 'bus']:
                x1, y1, x2, y2 = map(int, box.xyxy[0])
                bbox_width = x2 - x1
                
                # Thuật toán Pinhole Camera Model: D = (f * W) / w
                distance = (FOCAL_LENGTH * REAL_CAR_WIDTH) / bbox_width
                
                # Xác định trạng thái cảnh báo theo quy chuẩn
                if distance < (min_safe_dist * 0.5) or distance < 8.0:
                    color = (0, 0, 255)       # Đỏ: Nguy hiểm va chạm
                    status = "NGUY HIEM VA CHAM!"
                elif distance < min_safe_dist:
                    color = (0, 165, 255)     # Cam/Vàng: Vi phạm khoảng cách
                    status = "CANH BAO: QUA GAN"
                else:
                    color = (0, 255, 0)       # Xanh: An toàn
                    status = "AN TOAN"
                
                # Vẽ khung & thông số
                cv2.rectangle(frame, (x1, y1), (x2, y2), color, 2)
                cv2.putText(frame, f"{label.upper()} - {distance:.1f}m ({status})", 
                            (x1, y1 - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2)
                            
    # Hiển thị HUD trên màn hình
    cv2.putText(frame, f"Speed: {current_speed_kmh} km/h | Min Safe: {min_safe_dist:.0f}m", 
                (20, 40), cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 255), 2)
                
    cv2.imshow("Smart ADAS Vietnam - Camera iPhone 1x", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
